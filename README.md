# MOK KOM
**MOK KOM** es un sitio web para que los estudiantes compartan experiencias, consejos de estudio, puedan hacer apuntes y tarjetas de memorización los flashcards .

Caracteristicas
* **Publicaciones:** permite hacer  publicaciones, filtrarlas por categoría (*Estudio*, *Motivación*, *Consejos*), dar *Me gusta* a otras publicaciones y eliminarlas.
* **Mis apuntes:** para guardar, organizar y eliminar notas importantes de estudio
* **Mis Flashcards:** para crear tarjetas de estudio con pregunta y respuesta oculta para repasar materias
* **Perfil de usuario:** un pequeño cuadro en la esquina derecha arriba con foto, nombre e intereses del usuario
* **Diseño responsivo:** Interfaz que se adapta a celulares o otros dispositivos
